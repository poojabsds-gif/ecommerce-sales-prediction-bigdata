HBase Advanced Technology - E-Commerce Sales Prediction

Purpose:
HBase is used as a fast key-based storage layer for selected daily sales prediction results generated by Spark.

1. Open HBase shell

docker exec -it hbase bash
hbase shell

2. Check HBase status

status

3. Create the HBase table

create 'ecommerce_daily_sales', 'sales'

4. Verify the table

list
describe 'ecommerce_daily_sales'

5. Store Spark prediction results

put 'ecommerce_daily_sales','2011-07-25','sales:actual_revenue','26876.39'
put 'ecommerce_daily_sales','2011-07-25','sales:predicted_revenue','33936.75'

put 'ecommerce_daily_sales','2011-07-26','sales:actual_revenue','21635.56'
put 'ecommerce_daily_sales','2011-07-26','sales:predicted_revenue','44368.80'

put 'ecommerce_daily_sales','2011-07-27','sales:actual_revenue','25593.74'
put 'ecommerce_daily_sales','2011-07-27','sales:predicted_revenue','26930.67'

put 'ecommerce_daily_sales','2011-07-28','sales:actual_revenue','56243.32'
put 'ecommerce_daily_sales','2011-07-28','sales:predicted_revenue','28012.10'

put 'ecommerce_daily_sales','2011-07-29','sales:actual_revenue','18716.54'
put 'ecommerce_daily_sales','2011-07-29','sales:predicted_revenue','28734.12'

6. Retrieve stored results

scan 'ecommerce_daily_sales'

Design:
- Row key: SalesDate
- Column family: sales
- Columns: actual_revenue and predicted_revenue

Integration:
Spark performs distributed processing and Random Forest prediction.
HBase stores selected prediction results for efficient date-based retrieval.
